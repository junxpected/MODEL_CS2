# CS2 Demo Analyzer

Інформаційна система для аналізу ігрових ситуацій у **Counter-Strike 2** на основі моделі ймовірності перемоги (win probability).

Проєкт парсить demo-файли матчів, формує ознаки стану раунду й навчає модель XGBoost оцінювати шанс перемоги сторони CT. Мета — надалі знаходити об'єктивно вимірювані помилки гравця та команди: наприклад, втрачений раунд із переваги, невдалий еко-розмін або рішення в клатчі.

## Можливості

- Парсинг CS2 demo-файлів (`.dem`) через [AWPy](https://awpy.readthedocs.io/): раунди, тіки, вбивства, гранати та бомба.
- Підтримка стиснених FACEIT-демок у форматі `.zst`.
- Формування ознак: кількість живих гравців, сумарне здоров'я, вартість спорядження, час у раунді та мапа.
- Навчання XGBoost-моделі та оцінювання Accuracy і ROC AUC на окремому тестовому наборі раундів.
- Кешування вже оброблених демок, щоб не парсити їх повторно.

## Технології

Python, AWPy, Polars, XGBoost, scikit-learn.

## Швидкий старт

### Передумови

- Python 3.10 або новіший;
- `zstd` — лише якщо потрібно розпаковувати файли `.zst`.

### Встановлення

1. Клонуйте репозиторій та перейдіть до його каталогу:

   ```bash
   git clone https://github.com/junxpected/MODEL_CS2.git
   cd MODEL_CS2
   ```

2. Створіть і активуйте віртуальне середовище:

   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Windows: .venv\Scripts\activate
   ```

3. Встановіть залежності:

   ```bash
   pip install -r requirements.txt
   ```

4. Створіть каталог `demos/` і додайте до нього demo-файли `.dem` або `.zst`.

5. Запустіть навчальний пайплайн:

   ```bash
   python train_pipeline.py
   ```

Після виконання скрипт збереже проміжні семпли в `samples_cache/`, список оброблених файлів у `processed_demos.txt` і модель у `wp_model_final.json`.

## Приклади використання

Перевірити, чи коректно читається одна демка:

```bash
python parse_demo.py demos/match.dem
```

Обробити всі нові демки та навчити (або перетренувати) модель:

```bash
python train_pipeline.py
```

Приклад очікуваного фрагмента виводу:

```text
Знайдено 2 нових демок для обробки.
Мапа: de_mirage, раундів: 24
Точність: 78.0%
AUC: 0.815
Модель збережена: wp_model_final.json
```

Значення метрик залежать від кількості, якості та набору demo-файлів.

## Структура

| Файл | Призначення |
| --- | --- |
| `parse_demo.py` | Парсить CS2 demo-файл і повертає структуровані дані матчу. |
| `features.py` | Формує ознаки та семпли стану гри для навчання. |
| `train_pipeline.py` | Розпаковує нові демки, кешує семпли й навчає модель. |
